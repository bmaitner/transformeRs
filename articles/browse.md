and a photo of the original toy. Filter by faction, combiner team, role
or what kind of plot the palette suits, click a swatch to copy its hex

GitHub issue where you can propose different colours or attach a better

## Suggesting changes

Every palette here is an approximation read off toy photographs, so
corrections are welcome. Each card links to a prefilled GitHub issue
form:

- **Suggest a change** if a colour is wrong, missing, or should be
  removed, or if the description, alternate mode, year or photo is off.
  Say which hex codes you would add, change or drop and why; a photo of
  the toy under neutral light is the best evidence.
- [Request a
  character](https://github.com/bmaitner/transformeRs/issues/new?template=new-character.yml)
  if a Transformer or team you care about is not covered yet. The
  [wishlist](https://github.com/bmaitner/transformeRs/blob/main/WISHLIST.md)
  shows what is already queued.

You need a GitHub account to open an issue. If you would rather not,
email the maintainer listed in the package DESCRIPTION.
