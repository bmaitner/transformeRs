# transformeRs: Color Palettes Inspired by Generation 1 Transformers

Colour palettes based on the original Generation 1 Transformers toys,
plus ggplot2 colour and fill scales.

## Details

Start with
[`tf_palette()`](https://bmaitner.github.io/transformeRs/reference/tf_palette.md)
to pull colours from a character,
[`tf_palette_names()`](https://bmaitner.github.io/transformeRs/reference/tf_palette_names.md)
to list the available characters,
[`tf_team_palette()`](https://bmaitner.github.io/transformeRs/reference/tf_team_palette.md)
for one colour per member of a combiner team, and
[`scale_colour_tf()`](https://bmaitner.github.io/transformeRs/reference/scale_tf.md)
/
[`scale_fill_tf()`](https://bmaitner.github.io/transformeRs/reference/scale_tf.md)
to use them in ggplot2. Run
[`tf_show_palettes()`](https://bmaitner.github.io/transformeRs/reference/tf_show_palettes.md)
to see the palettes at once and
[`tf_find_palettes()`](https://bmaitner.github.io/transformeRs/reference/tf_find_palettes.md)
to shortlist the ones that suit a kind of plot.

Hex values are approximations curated from product photography on the
Transformers Wiki. transformeRs is a fan project and is not affiliated
with or endorsed by Hasbro or Takara Tomy.
